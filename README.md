# 鐵騎風雲（mb）

瀏覽器奇幻騎戰沙盒。完整規格見 [PLAN.md](PLAN.md)。

目前進度：**階段 1「戰場原型」**：單一戰場，玩家騎馬對 10 個 AI 步兵。

## 點樣運行

需要 Node.js 20 或以上。

```bash
npm install
npm run dev      # 開發伺服器
npm run build    # 類型檢查＋輸出靜態檔到 dist/
npm run preview  # 預覽 build 結果
npm run og       # 由 scripts/og-image.svg 重新生成 public/og-image.png
```

部署去 Cloudflare Pages：build command 用 `npm run build`，output directory 用 `dist`。

## 操作說明

| 按鍵 | 騎馬 | 步行 |
| --- | --- | --- |
| W／S | 加速／收韁（停定再撳 S 係後退） | 前後行 |
| A／D | 轉彎（要行緊先轉得） | 左右行 |
| Shift | 衝刺（耗馬力） | 慢行 |
| 空白鍵 | 跳躍 | 跳躍 |
| 滑鼠移動 | 望方向 | 望方向 |
| 左鍵 | 撳住蓄力，放手出招 | 同左 |
| 右鍵 | 撳住格擋 | 同左 |
| X | 放平騎槍（要揀騎槍、速度夠） | — |
| Q／E | 切換武器 | 同左 |
| F | 下馬 | 上馬（要喺馬附近） |
| Tab | 戰況表 | 同左 |
| M | 靜音 | 同左 |
| Esc | 暫停 | 同左 |

**出招方向**：撳左鍵嗰一刻，滑鼠最近向邊個方向移動就係邊個方向。

**格擋方向**：準星出現紅色箭嘴時，將滑鼠移向箭嘴方向再撳右鍵。撳住期間可以繼續移滑鼠改方向。

**盾牌**：只要擋喺正面，任何方向都擋到，但會損耗耐久，耐久歸零就碎。

**騎槍衝鋒**：Q／E 揀騎槍，速度去到約 29 km/h 以上撳 X，然後對準目標衝過去，會自動命中。

## 已完成功能

- 騎馬操控：慣性加速、轉彎半徑、唔可以原地掉頭、衝刺馬力、受傷減速、跳躍、上馬／下馬、馬死跌落
- 四種馬匹可揀：獵馬、草原馬、披甲戰馬、馱馬
- 四方向蓄力攻擊、方向格擋、盾牌耐久、破防
- 馬速傷害公式：`傷害 = 武器基礎傷害 × (1 + 相對速度 × 係數)`
- 撞人、騎槍衝鋒
- 武器：長劍＋盾、雙手斧、騎槍；敵方另有長矛同戰斧，分砍／刺傷害類型
- 10 個 AI 步兵（步卒、長矛手、斧兵）：包圍、輪流出手、舉防、閃避衝鋒
- 打擊感：頓幀、重擊慢動作、鏡頭震動、高速 FOV、粒子、合成音效
- 一屏介面：標題、暫停、結算畫面同戰場 HUD，全部繁體中文
- favicon、og:image（1200×630）、og 同 twitter meta
- 所有數值放喺 `src/data/`

調手感主要改 `src/data/combat.ts`、`horses.ts`、`weapons.ts`、`units.ts`。

## 已驗證

- `npm run build` 成功，開發版 console 冇錯誤
- 模擬全速衝鋒（獵馬 15.5 m/s，約 56 km/h）：長劍一擊 96，騎槍一擊 176–189，步卒生命 72，一擊即死
- 由靜止到全速約 4 秒；停定撳 A 唔會原地轉
- 方向格擋、盾牌、背後格擋失敗、馬死跌落、上落馬、勝利畫面都用腳本測過
