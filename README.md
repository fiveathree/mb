# 鐵騎風雲（mb）

瀏覽器奇幻騎戰沙盒。完整規格見 [PLAN.md](PLAN.md)。

目前進度：**階段 6「打磨」已做**：六個階段都有可玩版本，仲有陣法同十一個劇本；真人平衡同簡化位見「待確認」。

試玩：https://fiveathree.github.io/mb/

## 點樣運行

需要 Node.js 20 或以上。

```bash
npm install
npm run dev      # 開發伺服器
npm run build    # 類型檢查＋輸出靜態檔到 dist/
npm run preview  # 預覽 build 結果
npm run og       # 由 scripts/og-image.svg 重新生成 public/og-image.png
```

部署去 Cloudflare Pages：build command 用 `npm run build`，output directory 用 `dist`。

GitHub Pages：Settings → Pages → Source 要揀 **GitHub Actions**。之後每次 push 去 `main` 都會自動 build 同部署 `dist/`。唔可以揀 Deploy from a branch，因為嗰個模式派嘅係未 build 嘅原始碼，會得個白畫面。

### 指揮

先揀兵種，再落指令。

| 按鍵 | 作用 |
| --- | --- |
| 1／2／3 | 揀步兵／弓兵／騎兵 |
| 0 | 揀全軍 |
| F1 | 跟隨我 |
| F2 | 守住此處（陣地喺你前方） |
| F3 | 衝鋒 |
| F4／F5 | 散開／密集 |
| F6 | 停止射擊／自由射擊 |

數字鍵 4 揀法師。法術係第五類武器：去鐵匠買，放入武器欄，撳住左鍵施放，耗法力。

開局全軍守住陣地，你唔落令佢哋就唔會出擊，但敵人行近會自行迎擊。

### 戰鬥要點

- **出招方向**：撳左鍵嗰一刻，滑鼠最近向邊個方向移動就係邊個方向。
- **格擋方向**：準星出現紅色箭嘅時，將滑鼠移向箭嘴方向再撳右鍵。撳住期間可以繼續移滑鼠改方向。
- **盾牌**：只要擋喺正面，任何方向都擋到，但會損耗耐久。未舉盾都有機會擋到正面嚟嘅箭。
- **騎槍衝鋒**：用滾輪揀騎槍，速度去到約 29 km/h 以上撳 E，然後對準目標衝過去，會自動命中。
- **射擊**：撳住左鍵拉弓，準星個圈愈細愈準，拉滿先最準同最痛。箭有拋物線同飛行時間，遠距離要預判；騎馬時圈會變大。打中頭有 1.5 倍傷害。
- **兵種相剋**：長矛打騎馬目標有額外傷害；騎兵衝弓兵最有效；高處打低處有傷害加成。
- **士氣**：戰友陣亡、被包圍、受重傷同主將倒下都會扣士氣，歸零就潰逃。潰兵走出戰場就算離開。
- **你倒下**：部隊會繼續打完，鏡頭留喺你度。
